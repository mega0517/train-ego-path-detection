자동 라벨 (학습된 모델로 레일 검출)

학습된 모델로 모든 프레임의 레일을 직접 검출해 라벨을 생성합니다. 시드·추적이 없어 드리프트가 없으며, 도메인이 맞는 모델일수록 정확합니다. regression 모델은 좌·우 레일을 직접 예측해 라벨용으로 가장 깔끔합니다. 생성 후 어긋난 프레임만 수동 보정하세요.

SAM2 자동 라벨 (비디오 전파)

SAM2로 첫 프레임의 궤도를 세그멘테이션해 폴더의 모든 프레임에 전파합니다(연속 비디오 프레임에 적합, 도메인 무관). 프롬프트는 마우스로 궤도 위를 클릭해 지정하거나, 비우면 하단 중앙을 자동 시드합니다. 생성 후 어긋난 프레임만 보정하세요.
프롬프트 없음 → 자동(하단 중앙)
폴더와 주석 JSON을 설정하면 이미지를 불러옵니다.
